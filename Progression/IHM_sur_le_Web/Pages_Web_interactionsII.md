# Séance 3 – Pages Web et interactions

## **Activité : Découverte du JavaScript par l’analyse de scripts**

## **Objectifs de la séance**

À l’issue de la séance, tu dois être capable de :

- comprendre le rôle du JavaScript dans une page web,
- analyser un script JavaScript simple,
- identifier les éléments HTML et CSS utilisés par ce script,
- expliquer le fonctionnement d’un script à d’autres élèves,
- réutiliser plusieurs scripts JavaScript dans une même page web.

---

## **Organisation de la séance**

La séance se déroule en **deux temps** :

1. **Travail en groupes experts** : analyse approfondie d’un script JavaScript.
2. **Travail en groupes projets** : mise en commun des scripts pour créer une page interactive.

## **Consignes importantes**

- Le travail doit être collaboratif.
- Chaque élève est responsable de l’explication de son script.
- L’objectif n’est pas d’écrire beaucoup de code, mais de **le comprendre et le réutiliser**.

---

# **Partie 1 – Travail en groupe expert**

### **But de cette partie**

Tu travailles avec un petit groupe d’élèves sur **un script JavaScript précis**.

Ton objectif est de **le comprendre suffisamment bien pour pouvoir l’expliquer et le réutiliser**.

Chaque groupe expert travaille sur **un script différent**, avec un niveau de difficulté adapté.

# JavaScript

*Dans cette partie, on se concentre uniquement sur la partie JavaScript.*

### **Étape 1 – Lecture et compréhension globale**

1. Lis le script JavaScript dans son intégralité, sans chercher à le modifier.
2. Repère :
    - les variables déclarées,
    - les fonctions éventuelles,
    - les événements utilisés (clic, saisie, etc.).

### **Étape 2 – Analyse détaillée du script**

Complète collectivement l’analyse suivante :

- **À quoi sert ce script ?**
    
    (Quelle interaction ajoute-t-il à la page ?)
    
- **Quels éléments HTML sont utilisés ?**
    - balises concernées (button, p, div, etc.)
    - `id` ou `class` utilisés
- **Quelle action de l’utilisateur déclenche le script ?**
    
    (clic, saisie, autre)
    
- **Que modifie le script dans la page ?**
    - affichage d’un élément
    - ajout ou suppression d’une classe CSS
    - modification du style ou du contenu

# JavaScript + HTML

*Maintenant tu as accès au fichier HTML et le rendu sur une page web.*

### **Étape 3 – Commenter le code JavaScript**

Dans le fichier JavaScript :

1. Ajoute des commentaires pour expliquer :
    - La sélection des éléments HTML
    - Le rôle de l’événement
    - L’effet produit sur la page
2. Les commentaires doivent être compréhensibles par tous

Exemple de commentaire attendu :

```jsx
// Sélection du bouton qui déclenche l’action
```

### **Étape 4 – Identifier les éléments nécessaires dans le HTML**

Sur une feuille :

- Liste les éléments HTML indispensables au fonctionnement du script :
    - balises à créer,
    - `id` ou `class` obligatoires.
- Vérifie que le script fonctionne dans la page HTML fournie.

# **Partie 2 – Travail en groupe projet**

### **But de cette partie**

Tu travailles maintenant dans un nouveau groupe composé d’élèves ayant chacun étudié **un script différent**.

L’objectif est de **construire ensemble une page web interactive** intégrant tous les scripts.

### **Étape 1 – Présentation des scripts**

À tour de rôle :

1. Chaque élève présente son script aux autres :
    - rôle du script,
    - interaction proposée,
    - éléments HTML nécessaires.
2. Les autres élèves peuvent poser des questions.

## **Étape 2 – Organisation de la page HTML**

Collectivement :

1. Identifiez les éléments HTML nécessaires à tous les scripts.
2. Décidez où placer :
    - les boutons,
    - les sections,
    - les zones interactives.
3. Vérifiez que les `id` et `class` ne sont pas en conflit.

## **Étape 3 – Intégration des scripts**

1. Intégrez les différents scripts dans la page.
2. Vérifiez que :
    - chaque interaction fonctionne,
    - les scripts ne se bloquent pas entre eux.
3. Ajustez si nécessaire l’ordre du code ou les éléments HTML.

## **Étape 4 – Tests et corrections**

- Testez chaque interaction une par une.
- Corrigez les erreurs éventuelles.
- Vérifiez que la page reste lisible et cohérente.

# **Bilan de la séance**

À la fin de la séance, tu dois être capable de répondre à ces questions :

- Quel est le rôle du JavaScript dans une page web ?
- Comment JavaScript interagit-il avec le HTML et le CSS ?
- Comment analyser un script inconnu ?
- Pourquoi travailler en groupe permet-il de mieux comprendre le code ?
