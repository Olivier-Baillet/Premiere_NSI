# Différenciation

## Un accès à une documentation différente

Dans un premier temps, j’ai réalisé une fiche méthode présentant les différentes balises HTML utilisables et utiles. Celle-ci visait à différencier les élèves ayant déjà été confrontés au langage HTML l’année précédente, dans une logique de réinvestissement des connaissances, de ceux qui n’en avaient encore jamais abordé.

→ Je l’ai donner au élève sans acquis, pour qu’il n’est pas besoin d’être dans la recherche de l’information.

→ Pour les autres, ils auront accès à la documentation officiel plus fourni mais plus compliqué à naviguer (mais compétence : recherche dans une documentation)

## Activité de groupe

Dans le cadre de la séance consacrée aux interactions entre l’humain et la machine sur le Web, j’ai mis en place un dispositif de travail différencié autour de l’analyse et de la réutilisation de scripts JavaScript simples.

![image.png](Diff%C3%A9renciation/image.png)

La différenciation repose sur une organisation en deux temps.

Dans un premier temps, les élèves travaillent en groupes dits « experts », constitués de manière relativement homogène en termes de niveau.
Chaque groupe se voit attribuer un script JavaScript de difficulté adaptée, ciblant une interaction précise.
Cette phase permet aux élèves d’analyser le code, d’en comprendre le fonctionnement ligne par ligne, d’identifier les éléments HTML concernés et les styles CSS associés, puis de commenter le script afin d’en expliciter l’usage.

Dans un second temps, les élèves sont réorganisés en groupes hétérogènes.
Chaque élève devient alors porteur d’une expertise spécifique liée au script étudié précédemment. L’objectif est de concevoir collectivement une page web intégrant l’ensemble des interactions, ce qui nécessite que chaque élève explique le fonctionnement de son script aux autres membres du groupe et participe à sa réutilisation dans un nouveau contexte.
Ce travail favorise la verbalisation des connaissances, la coopération et la construction collective des apprentissages.
